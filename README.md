# Life OS — Telegram Bot

Бот для управления задачами, финансами, тренировками и заметками прямо из Telegram.

---

## 🚀 Запуск за 5 шагов (без программирования)

### Шаг 1 — Создай бота в Telegram

1. Открой Telegram и найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя (например: `My Life OS`)
4. Придумай username (например: `mylifeos_bot`)
5. BotFather даст тебе **токен** — скопируй его, он нужен на шаге 4

---

### Шаг 2 — Загрузи файлы на GitHub

1. Зайди на [github.com](https://github.com) → создай аккаунт если нет
2. Нажми **New repository** → назови `lifeos-bot` → Create
3. Нажми **Add file → Upload files**
4. Загрузи все 3 файла: `bot.py`, `requirements.txt`, `Procfile`
5. Нажми **Commit changes**

---

### Шаг 3 — Задеплой на Railway (бесплатно)

1. Зайди на [railway.app](https://railway.app) → войди через GitHub
2. Нажми **New Project → Deploy from GitHub repo**
3. Выбери репозиторий `lifeos-bot`
4. Railway сам найдёт `Procfile` и начнёт деплой

---

### Шаг 4 — Добавь токен бота

1. В Railway открой свой проект
2. Перейди в **Variables** (слева)
3. Нажми **New Variable**
4. Имя: `BOT_TOKEN`  
   Значение: токен из шага 1 (вида `7123456789:AAF...`)
5. Railway автоматически перезапустит бот

---

### Шаг 5 — Открой бота в Telegram

Найди своего бота по username и напиши `/start` — он ответит! ✅

---

## 💬 Команды бота

| Команда | Пример | Что делает |
|---|---|---|
| `/task` | `/task Позвонить врачу` | Добавляет задачу |
| `/done` | `/done 3` | Отмечает задачу #3 выполненной |
| `/list` | `/list` | Показывает все активные задачи |
| `/expense` | `/expense 15.50 Кофе` | Записывает расход |
| `/income` | `/income 2000 Зарплата` | Записывает доход |
| `/workout` | `/workout Бег 30 мин` | Логирует тренировку |
| `/note` | `/note Идея для проекта` | Сохраняет заметку |
| `/summary` | `/summary` | Полная дневная сводка |

## ❓ Частые вопросы

**Бот не отвечает?**  
Проверь Variables в Railway — токен должен быть без пробелов.

**Хочу обнулить данные?**  
В Railway: Files → удали `data.json`.

**Бесплатно ли это?**  
Railway даёт $5 кредитов в месяц — для бота этого хватит на годы.
